# GNBG - **Benchmark-Function Handbook**

> The Generalized Numerical Benchmark Generator (GNBG) is a parametric framework 
> used to create controllable test landscapes for continuous optimization.
> It utilizes a single parametric baseline function to generate diverse 
> landscapes by composing multiple basins of attraction.

---

## 1. Framework Overview

GNBG is designed to overcome the limitations of traditional fixed-formula benchmark suites. Instead of a set of static functions, it provides a configurable generator where researchers can specify morphological traits such as modality, ruggedness, symmetry, and variable interactions.

### Standard Suites

*   **GNBG-II:** The current standard suite for GECCO and CEC 2025 competitions, consisting of 24 specific problem instances ($f_1$ to $f_{24}$) generated by this framework.

---

## 2. Mathematical Definition

The baseline GNBG function is a **Min Composition** (lower envelope) of $o$ components:

$$f(\mathbf{x}) = \min_{k=1, \dots, o} \left\{ \Psi_k(\mathbf{x}) \right\}$$

Where each component $\Psi_k(\mathbf{x})$ represents a basin of attraction defined as:

$$\Psi_k(\mathbf{x}) = \sigma_k + \left( \sum_{i=1}^d \left( H_{k,i} \cdot T_k(z_{k,i}) \right)^2 \right)^{\lambda_k}$$

### Component Pipeline (Inside-Out)

| Stage | Operation | pyMOFL Implementation |
|-------|-----------|-----------------------|
| 1. Shift | $\mathbf{x} - \mathbf{m}_k$ | `ShiftTransform` |
| 2. Rotate | $R_k (\dots)$ | `RotateTransform` |
| 3. Ruggedness | $T_k(\dots)$ | `LogSinTransform` |
| 4. Condition | $H_k \cdot (\dots)$ | `ScaleTransform` (Diagonal) |
| 5. Core | $\sum (\dots)^2$ | `SphereFunction` |
| 6. Shape | $(\dots)^{\lambda_k}$ | `PowerTransform` |
| 7. Bias | $\sigma_k + (\dots)$ | `BiasTransform` |

## 3. Implementing in **pyMOFL**

In `pyMOFL`, the GNBG framework is supported via the `MultiBasinFunction` class, which is registered under both `multi_basin` and `gnbg`.

### Programmatic Construction (The Generator)

You can use `MultiBasinFunction` to generate custom landscapes or specific instances from the paper.

```python
import numpy as np
from pyMOFL.functions.benchmark import MultiBasinFunction

# Create a 10-D GNBG function with 5 basins
# 'rugged=True' enables the LogSinTransform modulation
func = MultiBasinFunction(dimension=10, n_components=5, rugged=True, seed=42)

# Evaluate a point
x = np.random.uniform(-5, 5, 10)
y = func.evaluate(x)
```

### Rotation via Interaction Matrices ($\Theta$)

GNBG supports building rotation matrices $R_k$ from upper-triangular interaction matrices $\Theta_k$ using Givens rotations (Algorithm 1).

```python
theta = np.zeros((10, 10))
theta[0, 1] = np.pi / 4  # Rotate variables 0 and 1
func = MultiBasinFunction(dimension=10, thetas=[theta])
```

### JSON-Driven Suite Access (GNBG-II)

The standard 24 competition instances are available via the `gnbg_suite` configuration.

```bash
# List all 24 functions in the GNBG-II suite
uv run pymofl suite list --suite-id gnbg_suite
```
